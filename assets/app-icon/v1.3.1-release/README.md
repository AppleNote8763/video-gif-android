# App Icon Backup

This folder stores the launcher icon PNG files restored from the `v1.3.1` release APK.

Keep these files as the visual reference for future Android APK builds. If Android icon resources are regenerated or replaced by default launcher images, copy the matching `ic_launcher*.png` files from each density folder back into:

```text
android/app/src/main/res/mipmap-mdpi/
android/app/src/main/res/mipmap-hdpi/
android/app/src/main/res/mipmap-xhdpi/
android/app/src/main/res/mipmap-xxhdpi/
android/app/src/main/res/mipmap-xxxhdpi/
```
